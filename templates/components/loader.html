{# Breathing butterfly loader. Both the markup and its CSS are inlined rather than linked, so the loader paints on the very first frame — before bulma.min.css or any script has been fetched. That is what makes the page appear to load "instantly" and then settle, instead of flashing unstyled content. It is removed by static/js/store/loader.js on window.load. The CSS carries a fallback animation that hides it after 6s regardless, so a JavaScript error can never leave a visitor staring at a permanent overlay. #}
